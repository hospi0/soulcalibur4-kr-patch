# 소울칼리버 IV (PS3) 한글 패치

> **내려받기:** [릴리즈 페이지](https://github.com/hospi0/soulcalibur4-kr-patch/releases/latest) — v0.9.
> 아시아판 디스크(BLUS30160)용입니다. RPCS3 에서 확인했습니다. 적용 방법·원본 MD5 는 묶음의 readme.txt 에 있습니다.
>
> 이 저장소에는 도구·번역 텍스트·작업 문서만 있습니다(게임 데이터·빌드 결과물 없음).

## 적용

1. `SoulCalibur4_PS3_KR_v0.9.zip` 을 풉니다.
2. `한글패치_적용.bat` 을 실행하고 게임 폴더(`PS3_GAME` 이 있는 폴더)를 끌어다 놓습니다.
3. 파일마다 원본 MD5 확인 → 원본 백업 → xdelta 적용 → 결과 MD5 확인 후 덮어씁니다(글 49개 + 글꼴 2개). 되돌리기는 `되돌리기.bat`.
4. RPCS3 의 시스템 언어를 **한국어** 나 **영어** 로 둡니다(한국어·영어 모두 영어 자리 글을 읽고, 그 자리에 한글이 들어갑니다. 일본어면 일본어가 나옵니다).

게임 실행 파일(EBOOT)은 건드리지 않고 글·글꼴 데이터 파일만 바꿉니다.

## 바뀌는 것

- 메뉴·옵션 설명, 시스템 메시지(저장·로드 안내는 PS3 시스템 창도 한글)
- 스토리·아케이드 대사와 자막, 승리·도발 대사, 데모 자막
- 캐릭터 크리에이션(파츠·스킬·스타일 설명), 타워 오브 로스트 소울즈
- 뮤지엄(캐릭터 프로필·일러스트 설명·칭호), 트레이닝, 튜토리얼
- 모든 캐릭터의 기술표(기술 이름·읽는 법·커맨드 설명)
- 고해상도 한글 글꼴(한자 칸 64px)

메뉴 큰 제목(STORY·ARCADE 등 장식 글꼴)과, 일본판에도 영문으로 나오는 곡명·저작권 표기는 원문 그대로입니다.

## 만든 방법(요약)

- 글 파일(`.ms?`·`regtext_?.dtp`)은 XOR 스트림 암호 + 꼬리 서명 `sc4-text` — `tools/mscrypt.py`·`tools/mstext.py`.
- 한글은 «대역 한자» 방식: 글꼴 텍스처(`gt_KanjiTexturePs3.nut`, JIS 순서 칸)의 한자 칸에 한글을 그리고, 글에는 그 칸의 한자를 UTF-8 로 씁니다 — `tools/build.py`·`tools/font_hires.py`(4096² 고해상도).
- 번역(일본어 원문 기준) → `tools/apply_fixes.py`(용어 통일·조사 맞춤·한자 병기 삭제·한국식 부호·일본어 음차 거센소리 `tools/kana_kr.py`·글 상자 폭 맞춤) → `work/text/fixed/` → 빌드.
- 배포 묶음 = `tools/make_dist.py`.

작업 기록은 `docs/00_초기조사.md` 에 있습니다.
